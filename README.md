# Isibindi GBV Website — WEDE5020W Part 1 and Part 3 source

## Project pages (five required pages)
- `index.html` — Home page and calls to action.
- `about.html` — About the organisation/project and its purpose.
- `services.html` — GBV awareness and support information; includes JavaScript live search/filter.
- `enquiry.html` — Enquiry form demonstration with native browser validation.
- `contact.html` — Contact information placeholders and general contact form demonstration.

## Part 3 JavaScript functionality
1. Responsive menu toggles open/closed and updates `aria-expanded`.
2. Support resources can be searched and filtered dynamically.
3. Copyright year updates automatically.
4. Enquiry/contact forms use browser validation and show a status message. Forms are demonstration-only and do not transmit or store personal data.

## SEO and accessibility
Each page has a unique title, meta description, keywords and theme colour. The site uses semantic page regions, skip links, form labels, keyboard focus indicators, responsive layouts and reduced-motion preferences. `robots.txt` and `sitemap.xml` are included. Replace `YOUR-DOMAIN.example` in sitemap.xml after hosting.

## Run and deploy
Open `index.html` in a browser, or use a local static server. For Netlify, drag the extracted project folder (the folder containing `index.html`) into the Netlify deploy area. No build command is needed. For GitHub, upload all files while preserving folders.

## Important safeguarding notice
This is an educational website prototype, not a crisis response, counselling, legal or medical service. The forms do not send or store information. Do not enter survivor stories or sensitive personal details. Verify emergency and GBV support contact information before publication.
